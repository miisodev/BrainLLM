How it works
Your memory should not be someone else's product.

Every note BrainLLM writes lives in a note application you control, in a format you can read without it. If this project disappeared tomorrow, your brain would still open, still be editable, and still make sense — which is the actual test of whether data is yours.

Questions

Is there a catch with the free tier?

No, and there isn't a tier. The whole project is MIT-licensed on GitHub. Sponsorship buys the Blueprint — a documentation artefact — and supports the work. It doesn't unlock code.

What do I actually need to run it?

A running TriliumNext instance, an ETAPI token, and Bun 1.0 or later. That's genuinely the hard part of setup, and it's also exactly why your data stays on your own machine.

Does it only work with Claude?

It's a standard MCP server, so any MCP-capable client can use it. Claude is what it's exercised against daily, and the OAuth surface exists specifically so claude.ai, Claude mobile and Cowork can connect — those can't send a static bearer token.

Why not just use a vector store?

Because you can't open one and read it. Every note here is a real note in a real editor — you can correct what the model wrote, by hand, and it will read your correction next session. That round trip is the whole point.

Is my data sent anywhere?

Only between your MCP client and your own Trilium instance. There's no BrainLLM service, no account, and no telemetry. The npm package and this site are the only things the project publishes.

Can I use it commercially?

Yes. MIT. Fork it, embed it, build a product on it. If it becomes load-bearing for you, sponsorship is the way to keep it maintained.

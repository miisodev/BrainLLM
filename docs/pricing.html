Questions

Fair questions

Is there a catch?

Setup. You run Trilium yourself and create a token before anything works. That's the price of the data staying yours.

What do I need to run it?

A running TriliumNext instance, an ETAPI token, and Bun 1.4.2 or later. To use it from claude.ai or the Claude apps, BrainLLM also has to be reachable over HTTPS.

Does it only work with Claude?

It's a standard MCP server, so any MCP client can use it. Claude is what it's used with every day, and the OAuth surface exists so claude.ai, the mobile apps and Cowork can connect.

Why not a vector store?

Because you can't open one and read it. Every note here is a real note in a real editor: correct what the model wrote by hand, and it reads your correction next session.

Is my data sent anywhere?

Only between your MCP client and your own Trilium. There is no BrainLLM service, account or telemetry. See the privacy policy.

Can I use it commercially?

Yes, under the MIT licence. If it becomes load-bearing for you, sponsorship is how it stays maintained.
